Redovisning

Här kommer mina redovisningstexter från de olika kursmomenten i denna kursen.

kmom01

1. I detta kursmoment har jag jobbat med mänga olika saker, speciellt med att komma igång med utvecklingsmiljö, labbmiljö och mitt kursrepo. Jag har checkat att alla utvecklingmiljö är nedladdade och uppdaterade. Jag kontrollerade även att npm, node och kursens verktyg fungerade.

2. Jag dessutom har lärt mig hur npm hanterar projektets beroende och hur npm samt ESlint används för att upptäcka olika sårbarheter. Jag har även tränat på att kontrollera ändringar med Git och blivit bättre med Github

3. Min TIL för detta kursmoment var fungerande utvecklingsmiljö såsom npm, eslint, och mycket mer. Det var intressant att få lära sig detta och kunna upptäcka problem i god tid.

kmom02

1. Övningen och uppgiften: Jag tycker att det gick bra med övningen och uppgiften, det var en väldigt bra vägledning i hemsidan tack för det. Det har varit vissa utmaningar längs vägen men det gick ändå bra. Övningen hjälpte mig att förstå hur man bygger upp en responsiv design och hur CSS påverkar mycket i en hemsida. Tycker att det är en stor utmaning att koda.

2. Responsiva webbplatser Den her delen tyckte jag var lite jobbig, då man behövde ontrollera om all responsivitet fungerade, förstora och förminska var lite krångligt. Men jag har fått bättre förståelse av det. Det blir enklare med andra plattformar med responsiv hemsida.

3. Jag är väldigt nöjd med utseendet för min webbplats By Mavera. Ett utav mina drömmar är att starta eget företah inom ljussektionen. Men jag kanske skulle ha fastnat på detaljerna ännu mer om det var nödigt.

4. JavaScript är u helt fantastiskt, det är hur användbart som helst. Programmeringsspråket gör det möjligt att skapa mer interaktiva webbplatser. I början var det lite svårt, det var enklare med grunder men svårare med medel, när man började fixa ett spel osv.

TIL var att lära sig mycket om resonsiva webbplatser, hur de fungerar på olika skärmar, hur man kodar fram det, hur man imprterar CSS filer på ett bättre sätt. Dessutom att anpassa sin layout och i sammarbete med JavaScript var spännande.

kmom03

1. Tema - temat för min webbplats är By Mavera, som handlar om ljusdesign och doftljus, tex stearinljus och bivaxljus. Jag ville skapa en fin och enkel hemsida som ger ett lugnande känsla och mysigt intryck. När jag valde färgerna var jag ute efter en varm och lugn känsla. Därför valde jag just dessa färger som passar in med dofter och ljus.

2. Jag kollade först och främst runt på olika webbsidor som presenterade sina produkter, jag har även plan om att öppna ett företag om just doftljus, då klickade det in. Jag var även noga med att sidan skulle vara enkel så att navigationen skulle bli enkel och tryggt.

3. En lärorik utmaning var att få HTML och CSS fungera, jag hade importerat andra CSS filer, då behövde jag kontrollera flera gånger så att ingen kod skrevs 2 ggr. Men det var en roligt och jobbig utmaning där man fick lära sig att vara noggran, för ibland fungerade inte koden riktigt, men det gick att lösa.

4. Mitt råd till nybörjare är att läsa mycket om grunderna, testa olika saker och försöka hålla det enkelt, man ska inte förvänta en riktigt bra CSS på en hemsida när man är nybörjare. Desstuom är det okej att göra misstag, det är så man lär sif

5. Mitt TIL för detta kursmoment var att lära sig mycket mer om CSS. Hur man använder det, hur en hemsida kopplas med HTML koder, section, id osv. Dessutom kontrollera så att ingen kod kommer dubbelt. Jag känner att jag får en bättre försåelse för hur CSS, HTML och JavaScript sammarbetar när man bygger en hemsida.

kmom04

1. Förstår du hur HTML/CSS/JavaScript hänger ihop när vi utvecklar för webben? Ja, jag har bättre koll på hur HTML, CSS och Javascript samarbetar. HTML skapar strukturen på sidan, CSS bestämmer hur sidan ser ut och JavaScript gör sidan interaktiv och funktionell.

2. Känner du att du har koll på hur vi kan manipulera HTML elementen med hjälp av JavaScript? Ja, jag har lärt mig en hel del, speciellt när man skriver koden själv. Har tex lärt mig hur man kan ändra HTML-element med JavaScript, tex genom klasser, storlekar och färger, ändra och skapa nya element.

3. Hur tycker du att din kodstruktur blev över uppgiften? Jag tycker att min kodstruktur blev bra, jag tog hjälp av internet, delade upp koden i HTML, CSS och JavaScript vilket kommer att göra det tydligare och enklare att förstå. Ibland blev det fel, men jag felsökte och lärde mig en hel del, utan att göra fel kan man inte utveckla sig.

4. Vilken är din TIL för detta kmom? Min TIL var att utveckla mig inom JavaScript, alltså att man kunde manipulera en hel del med JavaScript var fantastiskt. Det var intressant med tangentbordknappar och kunna styra de inom hemsidan man själv skapade, det hade jag funderat på hur länge som helst.

kmom05

1. Det gick väldigt bra att lösa uppgiften, även om jag behövde felsöka några delar av koden. Jag lärde mig dessutom hur man hämtar data från JSON-filer med Fetch API och visa information för olika länder i en tabell. Det var även roligt att lära sig hur man markerar vinnaren med en fgrön bakgrund.

2. Man kan tydligt se fördelarna med async/await eftersom det underlättar kodläsningen och hjälper även med att hämta datan innan jag börjar använda den, ett säkert sätt ju!

3. Det krångligaste med denna uppgift var att man glömde lägga till vissa filer som gjorde att CSS inte fungerade, alltså glömde jag helt och hållet att koppla CSS med HTML och jag förstod inte riktigt vad som pågick! Jag behövde även rätta småfel i Javascript såsom bokstäver och tecken.

4. Min TIL för denna kursmoment var att lära sig om Fetch API, Async/await och lite mer om hur Javascript kan hantera en hemsida,

kmom06

1. Det gick helt ok att lösa uppgiften, tyckte att några delar inom JavaScript var lite jobbiga, därför fick jag felsöka och rätta till koden, men det var spännande!

2. Jag älskade JavaScript och tycker att det är betydligt användbart men man behöver ganska mycket tid att lära sig, tycker det är lite för mycket att lära sig ibland men det är spännande även om det är svårt. Ibland är det också svårt att hitta sina fel om man har skrivit en lång kod. Men smått och svårt, jag lär mig vid varje video och vid varje tillfälle.

3. Min TIL är att jag har lärt mig hur JavaScript används för att ändra HTML-element, hur man hanterar klickhändelser, och hur man kan fetcha bilder från nätet, skönt o slippa att ladda ner. Har även lärt mig hur man felsöker, console hjälper sååå mycket, vilket är skönt och felsöka om man har missat något eller om något har gått fel.
